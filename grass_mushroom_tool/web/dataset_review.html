如何判断深度好坏
  1. 先看时间差。优先检查 Δt=0 的组。非零时间差不代表空间标定错误，但移动相机或目标会造成错位。本页尚未做实测精度标定。
  2. 用叠加图核对菇体轮廓。切换右图到叠加，调节深度占比；菇帽的深度凸起应落在同一个菇帽上。寻找多个位置都存在的偏移，而不是只看一个边缘。伪彩范围只影响显示，不改变深度值。
  3. 框选单个菇体内部。检查非零比例、深度是否成片连续；黑色 0 是空洞，不能当作 0 mm 距离。全图非零比例不是菇体可用率，也不是准确率。不要把背景一起框入后据此评价菇体。
  4. 检查边缘和小菇。边缘大面积黑洞、拖尾、深度跨到背景，会影响尺寸或抓取点。表面有坡度时深度自然变化，P10–P90 范围大不能单独判为噪声。
  5. 验证测量误差。本页单帧无法评价重复性或绝对精度。固定相机和目标拍多帧，再用已知尺寸/距离实测对比。这里的 Z 是光学轴深度，不是到相机中心的斜距，也不是菇高。
