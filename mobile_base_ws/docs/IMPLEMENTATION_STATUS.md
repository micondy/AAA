# 底盘实施状态

更新日期：2026-09-01。

## 已实现并实机确认

- SocketCAN 双总线：`can0` 为 ZLAC8015D 行走电机，`can1` 为达妙 DM4340P 转向电机。
- 达妙四电机通信与绝对位置读取；实机轮位映射为左前 `02/12`、右前 `01/11`、左后 `04/14`、右后 `03/13`。
- 最新实车反馈确认左侧 +45°实际朝右前：左侧方向及零偏同步取反，四轮方向现为 -1；旧的左右镜像假设已撤销。已取消外侧姿态与轮速补丁，改用统一有界舵轮规划。尚待实车复验。
- 2026-08-31 已把当时四轮机械位置标为各自软件零位；运行配置零偏依次为左前 `+2.262259`、右前 `-0.712939`、左后 `-1.086130`、右后 `+1.643564` rad。
- ZLAC 节点 5、6 通信、使能、速度命令、转速反馈和故障读取。
- 现有接线映射：节点 5 为前轴，节点 6 为后轴；通道 1 为左轮，通道 2 为右轮。
- `ros2_control` 硬件接口、四轮四转控制器、mock 启动、标定/测试脚本和网页调试界面。
- 底盘配置可通过 YAML 与网页维护；支持单轮转速、单轮转向角和达妙模式配置。
- 网页已去除单用户研究场景不需要的控制租约；整车采用点击启用/点击停止，单轮维护保持按住执行，并保留命令超时、维护看门狗和可选访问令牌。

## 当前软件能力

- 实车 `robot.launch.py` 默认启动底盘驱动、`ros2_control`、四轮四转控制器、状态发布和网页后端。
- 网页可以配置两路 CAN、四个达妙 ESC/MST ID、两个 ZLAC 节点及通道、方向、零偏、减速比和安全限值。
- 网页维护模式可以读取达妙绝对位置、保存机械零偏，并单独控制一个轮组的转向相对角和轮速。
- 网页正常模式通过 `/swerve_controller/cmd_vel` 控制整车，输入包含 `vx`、`vy`、`wz`。
- 四轮四转运动学已支持前后、横移、斜移、原地自转、弧线转弯和三自由度组合运动。
- 控制器包含转向最短路径/轮速反转优化、最大轮速等比例限幅、0.25 秒命令超时停车和轮速里程计。
- 转向机械范围限定为相对标定零位 `-90°～+90°`；运动学使用等价轮向与轮速反转避免越界，维护命令也执行绝对角联锁。
- 单轮维护同时支持绝对目标角和相对当前角，越界自动夹到 ±90°；网页显示实际角、锁存目标和修正结果。
- 四台转向默认速度降为 0.15 rad/s；整车控制在所有参与运动的舵轮进入 5°误差范围前禁止行走，随后使用余弦补偿平滑放行。
- 网页增加前进、后退、左右横移、左右前斜行、左右原地旋转和停车保持轮向预设；预设不会自行启用电机。
- 统一选择限位内的等价轮向；大幅换向等待四轮实际轮速稳定停止再转向。转向目标限速、轮速共同斜坡；零命令保持实际角，越限反馈拒绝继续运动。旧边界夹角迟滞已移除。
