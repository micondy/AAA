## 1. 一句话说明

本工程已打通从网页/ROS 2 速度指令、四轮四转运动学、`ros2_control` 到两路 CAN 实物电机的完整控制链，已在四轮架空条件下完成轮序、转向零位、转向正反和行走正反的低速核对。它已适合继续做落地低速验收和里程计/导航调参，但不应将“架空方向正确”视为“已完成整车落地、建图和自主导航验收”。

## 3. 系统结构

```mermaid
flowchart LR
    B[浏览器网页] --> W[mobile_base_web_console]
    R[ROS 2 上层 / Nav2] --> C[/swerve_controller/cmd_vel]
    W --> C
    C --> S[mobile_base_swerve_controller]
    S --> H[ros2_control + mobile_base_driver]
    H --> C0[can0: ZLAC 行走]
    H --> C1[can1: DM 转向]
    H --> J[/joint_states]
    S --> O[/swerve_controller/odom]
    J --> W
    O --> W
    M[/rtabmap/map] --> W
    N[/nvblox_node/mesh] --> W
```

### ROS 2 包分工

- `mobile_base_driver`：SocketCAN 硬件接口，DM-J4340P-2EC 转向电机通信，ZLAC8015D CANopen 行走驱动。
- `mobile_base_swerve_controller`：四轮运动学、限位内角度优化、换向刹车、对齐联锁、速度/加速度限制和里程计。
- `mobile_base_description`：底盘 Xacro/URDF、轮组关节、车体尺寸和 `ros2_control` 硬件描述。
- `mobile_base_bringup`：统一启动、配置注入、CAN 设置、电机模式检查、标定和独立硬件测试。
- `mobile_base_web_console`：局域网网页、ROS 状态聚合、安全模式切换、整车/维护指令、零位和 YAML 配置管理。

## 4. 实物映射与当前标定

### CAN 分配

| 接口 | 速率 | 设备 | 协议 |
|---|---:|---|---|
| `can0` | 500 kbit/s | ZLAC8015D：节点 5 前轴，节点 6 后轴 | 经典 CAN / CANopen |
| `can1` | 1 Mbit/s | 4 台 DM-J4340P-2EC 24V | 经典 CAN，位置速度模式 |

### 轮组映射

| 轮组 | DM `motor/master` | DM 方向 | 当前零偏 rad | ZLAC 节点/通道 | 行走方向 |
|---|---|---:|---:|---|---:|
| 左前 FL | `02/12` | -1 | `+0.7230847478` | `5/1` | -1 |
| 右前 FR | `01/11` | -1 | `-2.2151515484` | `5/2` | +1 |
| 左后 RL | `04/14` | -1 | `-1.6867287159` | `6/1` | +1 |
| 右后 RR | `03/13` | -1 | `-2.0716021061` | `6/2` | -1 |

当前实车尺寸参数为：轮半径 `0.10 m`、轴距 `0.60 m`、轮距 `0.50 m`、车体 `0.62 × 0.58 m`、轮宽 `0.0683 m`、轮心相对转向轴偏置 `0.043 m`。

> **配置源优先级：**实车的唯一当前基准是 `~/.config/mobile_base/chassis.yaml`，不是包内模板 `src/mobile_base_bringup/config/chassis.yaml`。包内模板的零偏、几何和方向可能过期，不得直接覆盖运行配置。

网页保存底盘配置时会对原文件做备份，备份目录为 `~/.config/mobile_base/backup/`。底盘几何、电机映射、方向和零偏的变更都需重启底盘节点后生效。

### 横移姿态的特殊规则

四个转向轴与轮心存在 43 mm 偏置。当横移的两个等价轮向路径成本相差不超过 5° 时，优先使轮心向轴距外侧展开：

- FL `-90°`
- FR `+90°`
- RL `+90°`
- RR `-90°`

如果另一个解的转向路径明显更短，控制器仍优先最短路径。不同轮的转角和电机转速符号可不同，判断正确与否应看四个轮实际滚动速度矢量是否一致。

## 5. 网页能做什么

默认监听 `0.0.0.0:8080`，浏览器访问 `http://底盘电脑IP:8080`。

- 查看网页服务、控制器、CAN、诊断、八个关节、里程计和导航状态。
- 按实际尺寸绘制俯视底盘，显示转向轴、轮心偏置、轮角、RPM、行走符号和目标/实际滚动矢量。
- 在 `NORMAL` 模式使用摇杆、旋转滑条或预设按钮控制整车。
- 动作按钮单击后连续发送指令；切换动作不需先停止；再点激活按钮或“立即停车”停止。
- 在 `MAINTENANCE` 模式进行单轮低速调试、相对/绝对转向和零位标定。
- 编辑底盘几何、电机映射、方向、零偏和安全上限，保存时校验并备份。
- 显示 RTAB-Map 占据栅格和里程计轨迹，选择并发送 Nav2 目标。
- 有 Nvblox Mesh 时显示下采样三维点。

主要 HTTP API：

- 读取：`GET /api/status`、`/api/map`、`/api/scene3d`、`/api/config`、`/api/chassis`
- 配置：`PUT /api/config`、`PUT /api/chassis`
- 控制：`POST /api/control/cmd_vel`、`/api/control/stop`、`/api/mode`
- 导航：`POST /api/navigation/goal`、`/api/navigation/cancel`
- 维护：`POST /api/maintenance/command`、`/api/calibration/read`、`/api/calibration/save`

如果设置环境变量 `MOBILE_BASE_WEB_TOKEN`，控制类 API 需携带令牌。未设置时后端会警告，局域网内任意设备都可访问控制接口，因此不得暴露到公网。

## 6. 安全联锁

1. `start_robot.sh` 先配置 CAN，再确认 4 台 DM 均可通信且为 `pos_vel`，然后确认 ZLAC 节点 5/6 为 Profile Velocity。任一检查超时就拒绝启动。
2. DM 启动时必须成功读取 `PMAX/VMAX/TMAX` 和输出轴绝对位置，无有效量程或绝对角不会发送运动指令。
3. 转向硬限制为 ±90°，转向反馈超时、跳变或超限都进入故障处理。
4. 大角度换向时先停行走；实际轮速低于 `0.05 rad/s` 并稳定 `0.15 s` 后才转向。
5. 任一参与运动的轮转向误差超过 5°，四个行走轮均保持零速，不会单轮抢跑。
6. 整车控制器 `0.25 s` 未收到指令就归零；网页后端命令看门狗默认 `0.5 s`；ZLAC 通信掉线保护每次启动设置为 `500 ms`。
7. 网页失焦、切换标签页或关闭时会尝试停车；后端和控制器超时作为后续保护。
8. 进入维护模式必须显式确认四轮已架空，维护转速和转角另有更严格限制。

> 网页“立即停车”、软件超时和 CAN 看门狗都不是符合安全标准的实体急停。落地试验时必须有可直接切断动力的实体急停/断电手段和现场监护人。

## 11. 排故要点

- **启动脚本拒绝启动：**先查 `ip -details -statistics link show can0` 和 `can1`，再分别跑 DM/ZLAC 独立检查；不要为了启动而删除联锁。
- **轮子序号对但物理方向反：**区分 `steering.direction`、`drive.direction`和 `offset_rad`；三者含义不同，不得用修改零偏掩盖方向错误。
- **横移轮角看似一正一反：**先看轮上的目标/实际滚动矢量，因为等价角折叠会同时改变转角和轮速符号。
- **轮角到位但底盘不走：**查看 5° 对齐联锁、其他轮的反馈、命令超时和控制器模式。
- **网页按钮无效：**先确认模式为 `NORMAL`、网页显示服务在线、浏览器没有使用旧缓存；强制刷新后复试，并观察 `/swerve_controller/cmd_vel`。
- **网页显示与实物不一致：**网页画的是 ROS 反馈和当前 YAML 几何。先确认实际启动使用的 `chassis_config` 路径，再查轮序、方向和零偏。
- **SLAM 启动失败：** `start_online_slam.sh` 会先等待 `/swerve_controller/odom`；检查底盘已启动、两个工作区已构建且 `ROS_DOMAIN_ID` 一致。

## 13. 交接时最重要的三条

1. **不要用包内模板覆盖 `~/.config/mobile_base/chassis.yaml`。**当前零偏和方向是重新机械安装后逐轮调出的。
2. **不要根据动画的正负号直接改电机方向。**应在架空、单轮、小角度/低转速下，以轮子实际滚动矢量判断。
3. **当前完成的是架空方向验证，不是落地自主导航验收。**落地必须从最低速、单动作开始，并保留实体断电手段。
