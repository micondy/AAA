# 底盘、网页与在线 SLAM 运行手册

这是底盘电脑上电后的固定操作入口。底盘和在线 SLAM 分两个终端运行，日志互不覆盖。

## 1. 终端 1：启动底盘和网页

先给达妙、中菱和电机供电，连接两只 USB-CAN，然后运行：

```bash
cd /media/scc/Windows_D/AAA/mobile_base_ws
./start_robot.sh
```

脚本会配置两路 CAN，检查四台达妙均为 `pos_vel` 模式，检查中菱节点 5、6，
然后启动底盘、控制器和网页。任意设备超时或模式错误时会中止启动。

## 2. 终端 2：启动实时 D435i 和在线 SLAM

确认终端 1 仍在运行，再打开新终端：

```bash
cd /media/scc/Windows_D/AAA/mobile_base_ws
./start_online_slam.sh
```

该脚本启动实时 D435i 和 RTAB-Map，使用 `/swerve_controller/odom` 底盘里程计，
在 `/rtabmap/map` 持续发布栅格图。这是在线建图，不是 rosbag 离线回放。

默认数据库是 `~/.ros/mobile_base_online.db`，默认续建且不删除旧数据。建新图时请换新文件名：

```bash
SLAM_DATABASE_PATH="$HOME/.ros/room_002.db" ./start_online_slam.sh
```

有多台 RealSense 时必须指定 D435i 序列号：

```bash
D435I_SERIAL=346122070466 ./start_online_slam.sh
```

**重要：**默认相机位姿 `xyz=0.10 0 1.12 m`、`rpy=0 0.20944 0 rad` 仍是临时值。
实车固定安装后必须标定；标定前可查看实时建图链路，不得用于 Nav2 自主行驶。
标定后可传入 `CAMERA_X/Y/Z/ROLL/PITCH/YAW` 环境变量。

## 3. 打开网页

在底盘电脑运行 `hostname -I`，同一局域网的浏览器访问：

```text
http://底盘电脑IP:8080
```

更新后第一次访问使用 `Ctrl+Shift+R` 强制刷新。页面显示“`SLAM · x.xs`”表示正在收到
`/rtabmap/map`；“地图离线”表示没收到地图话题，不表示正在运行“离线 SLAM”。

## 4. 正确停止与按需关机

所有启动脚本只负责停止程序，不会自动关闭电脑。只有操作员明确决定关闭实车电脑时，才
执行下面最后一条 `sudo poweroff`；仿真运行不需要关机。

1. 在网页点击“立即停车”。
2. 在 `start_online_slam.sh` 终端按 `Ctrl+C`，等 RTAB-Map 关闭数据库。
3. 在 `start_robot.sh` 终端按 `Ctrl+C`。
4. 确认两个程序都退出后运行：

```bash
sudo poweroff
```

等底盘电脑完全关机后，再关闭驱动器和电机电源。

## 5. 启动失败时检查

```bash
ip -details -statistics link show can0
ip -details -statistics link show can1
ros2 topic hz /swerve_controller/odom
ros2 topic hz /sensors/nav_camera/color/image_raw
ros2 topic hz /rtabmap/map
```

CAN 应为 `UP`、`ERROR-ACTIVE`，错误计数不持续增加。如果报 `No RealSense devices were found`，
先用 `lsusb` 检查相机是否被 Linux 枚举。

检查四台达妙模式：

```bash
ros2 run mobile_base_bringup configure_damiao_mode.py \
  --config ~/.config/mobile_base/chassis.yaml \
  --interface can1 --timeout 1.5 read --require-mode pos_vel
```

| 轮位 | ESC ID | Master ID |
|---|---:|---:|
| 左前 | `0x02` | `0x12` |
| 右前 | `0x01` | `0x11` |
| 左后 | `0x04` | `0x14` |
| 右后 | `0x03` | `0x13` |

## 7. 实车测试顺序

1. 首次测试架空四轮并准备实体断电。
2. 确认达妙模式、角度反馈和中菱节点均正常。
3. 维护模式逐轮测试 `0°、+15°、-15°`。
4. 以 5%～10% 速度架空测试前后、横移、斜行和旋转。
5. 四轮方向全部确认后才能落地。
6. 落地低速确认里程计后，才启动在线 SLAM。

转向反馈越限、跳变或任意电机超时时，不得继续测试。

## 8. 运行配置位置

- 底盘配置：`~/.config/mobile_base/chassis.yaml`
- 历史备份：`~/.config/mobile_base/backup/`
- 在线 SLAM 数据库：`~/.ros/mobile_base_online.db`

网页保存硬件参数后，需重启 `start_robot.sh` 才能让大多数底层参数生效。

## 9. 仿真：在线建图、Nav2 与网页

仿真与实车分开启动，不给 CAN 和电机上电。终端 A 启动 Isaac Sim：

```bash
source /opt/ros/jazzy/setup.bash
export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
cd /media/scc/Windows_D/AAA/robot_research_ws
/home/scc/isaac-sim-standalone-6.0.1-linux-x86_64/python.sh \
  tools/isaac_sim/run_mobile_manipulator.py --ros --enable-nav-rgbd \
  --nav-camera-width 320 --nav-camera-height 240 --nav-camera-hz 10
```

看到 Isaac 窗口和 ROS `READY` 信息后，终端 B 启动 RTAB-Map 在线建图、Nav2、RViz 和
网页：

```bash
cd /media/scc/Windows_D/AAA/robot_research_ws
source tools/source_robot_stack.bash
export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
ros2 launch mobile_navigation_bringup mobile_base_sim_navigation.launch.py \
  database_path:=$HOME/.ros/isaac_mobile_base_online.db \
  rtabmap_mode:=mapping fresh_map:=false
```

浏览器打开 `http://127.0.0.1:8080/#visualization`。`mapping` 是实时在线增量建图，默认
继续使用数据库；要从零建一张新图时，优先换一个新数据库文件名。`fresh_map:=true` 会删除
所选数据库，只能在确认不需要旧图时使用。

速度链如下：网页 `/cmd_vel_web`；Nav2 `/cmd_vel_nav` -> 平滑器 -> 碰撞监控 ->
`/cmd_vel_nav_safe`；优先级仲裁器唯一输出 `/cmd_vel` 给 Isaac。网页手动操作会优先于
Nav2，转向时仿真器会等待四轮转角误差进入 5° 后再驱动车轮。

运行中可另开终端检查：

```bash
cd /media/scc/Windows_D/AAA/robot_research_ws
source tools/source_robot_stack.bash
ros2 param get /rtabmap/rtabmap Mem/IncrementalMemory
ros2 lifecycle get /planner_server
ros2 lifecycle get /controller_server
ros2 topic info /cmd_vel
```

期望在线建图参数为 `true`，两个 Nav2 server 均为 `active`，`/cmd_vel` 只有一个发布者。
网页能手动开车但部分导航目标失败时，先在 RViz 检查目标是否位于当前已建图的空闲区域，
再检查 global/local costmap、机器人定位和全局路径。在线建图过程中，新观测到的障碍会让
原先可走的路线失效；不要直接用“继续失败目标”掩盖问题。

停止时先在网页点“立即停车”，再在终端 B 按 `Ctrl+C` 并等待数据库关闭，最后在终端 A
按 `Ctrl+C` 退出 Isaac Sim；不要执行关机命令。
