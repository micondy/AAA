# 动态障碍侵入回归

该目录保存 Isaac Sim 中“底盘已经运动后，障碍才进入前向视场”的安全回归结果。测试使用
真实渲染的顶部 RGB-D 点云、独立 `/safety_test/cmd_vel_in` 输入以及生产配置中的
`FrontStop` 多边形，collision monitor 输出直接驱动仿真 `/cmd_vel`。

## 2026-09-21 正式结果

结果文件：`dynamic_intrusion_20260921_122038.json`，总结果 PASS。

点云源超时设为0.75 s。净空由已知障碍放置距离、模型尺寸、机器人前缘和 odom 前进量估算，
不是碰撞传感器测量。每种工况目前只有一次确定性回归，因此结果用于防回归，不能给出统计
置信度，也不能外推为真实底盘的制动性能或安全认证。

测试命令会发布通用 `/cmd_vel`。只允许在关闭真车驱动、与真车隔离的 Isaac ROS domain 中
执行，并且必须显式传入 `allow_motion:=true`；默认值为 false。
