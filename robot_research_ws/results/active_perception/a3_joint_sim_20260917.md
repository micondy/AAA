# A3 固定相机底盘 NBV 联合仿真记录

- 日期：2026-09-17
- 结果：PASS
- 范围：验证“RGB-D 目标观测 → 跟踪/锁定 → Target Belief → 占据地图过滤 → Nav2 路径查询 → NBV 评分”；不包含自动导航执行。

## 配置

- Isaac Sim 自制四轮四转底盘 + 官方 OpenArm 组合资产
- 顶部导航 RGB-D：320×240，10 Hz
- 合成目标：绿色方块，稳定 ID `green_target_0001`
- 地图数据库：`maps/isaac_indoor_external_odom_04.db`
- 定位/导航：RTAB-Map + Nav2
- 候选：0.6/0.8/1.0 m 三圈，每圈 12 个，共 36 个

## 结果

- Belief 连续接收并融合 300 帧以上目标观测。
- 36 个候选中有 3 个通过地图、净空、视线与可见性预筛，随后完成 Nav2 `ComputePathToPose` 查询。
- 最佳候选：索引 25。
- Nav2 路径长度：2.954 m。
- 预期信息增益：0.9210 nats。
- 综合得分：0.9877。
- RViz 能显示 `/rtabmap/map`、目标 belief、候选 markers 与最佳视角。
- 触发规划期间底盘未移动，符合 A3 的只规划安全边界。

## 联调中修复

1. Isaac 负载下图像时间戳可能暂时领先动态 TF，Belief 改为缓存原始观测并按原时间戳重试，不使用 latest TF 近似。
2. NBV 地图输入明确改为 `/rtabmap/map`，与当前导航基线一致。
3. 新增 `sim_active_perception.launch.py`，统一编排导航、感知、Belief、NBV 与 RViz，避免重复发布机器人 TF。
